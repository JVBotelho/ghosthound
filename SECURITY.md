# Security Policy

## Supported Versions

Only the latest version of GhostHound is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in GhostHound or its component crates, please report it privately.
**Do not** open public issues for security vulnerabilities.

Please send an email to: **zmtsn3xg.refining218@passinbox.com**

You should expect a response within 48 hours. If the vulnerability is confirmed, we will coordinate a fix and advisory.
